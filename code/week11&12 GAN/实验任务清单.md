## 迁移学习核心思路

### 什么是迁移学习？

```
预训练模型 (ImageNet)     →    微调适配 (猫狗/CIFAR-100)
已在1000类学过特征              只需学习新任务
```

**本质**：站在"巨人肩膀上"——利用已学到的通用特征，快速适应新任务

### 实现步骤

#### 1. 加载预训练模型
```python
model = models.resnet50(pretrained=True)
```
- ResNet50 在 ImageNet (140万张图片，1000类) 上预训练
- 已学会识别边缘→纹理→形状→物体的层次特征

#### 2. 冻结特征层
```python
for param in model.parameters():
    param.requires_grad = False  # 锁住预训练权重
```
**目的**：保留学到的通用特征，不被破坏

#### 3. 替换分类头
```python
model.fc = nn.Linear(2048, 2)  # 1000类 → 2类 (猫/狗)
```
**目的**：适配新任务的类别数

#### 4. 分层解冻 + 差异化学习率
```python
# fc层: 大学习率 1e-3 (从头学)
# layer4: 中学习率 1e-4 (微调)
# layer3: 小学习率 1e-5 (轻微调整)
```
**目的**：高层特征针对性调整，底层特征保持稳定

### 结构图解

```
┌─────────────────────────────────────────────────────┐
│                  预训练 ResNet50                     │
├─────────────────────────────────────────────────────┤
│  conv1 → layer1 → layer2 → layer3 → layer4 → fc    │
│   ❌       ❌       ❌       ✅        ✅      ✅    │  ← 解冻策略
│  1e-6     1e-6     1e-5     1e-5     1e-4    1e-3  │  ← 学习率
└─────────────────────────────────────────────────────┘
          冻结 (保留通用特征)     微调 (适配新任务)
```

### 为什么有效？

| 层 | 学到的特征 | 迁移价值 |
|----|-----------|----------|
| 底层 (conv1, layer1) | 边缘、纹理 | 通用性强，直接复用 |
| 中层 (layer2, layer3) | 形状、部件 | 部分通用，轻微调整 |
| 高层 (layer4, fc) | 语义组合 | 任务相关，重点微调 |

**猫狗任务恰好**：ImageNet 已包含猫狗类别 → 预训练特征高度匹配 → 微调效果好

### 关键优势

```
从零训练                    迁移学习
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
需要大量数据                只需少量数据
训练时间长                  训练时间短
容易过拟合                  泛化能力强
```
